# Crosswind Garage v5.0 — Maintenance, Vehicle Tools & Emergency Fallback Center

Live App: **https://esp046-cyber.github.io/isuzucrosswindcarguide/**

### v5.0 Changelog & Audit Fixes
- **UI/UX & Mobile Layout Fixes:** Full-width variant selector without text clipping; compact sticky header and horizontally scrollable 9-tab bottom bar (`Dashboard`, `Maintain`, `Parts`, `History`, `Cost/Fuel`, `Diagnose`, `Tools`, `Specs`, `Emergency`); `scroll-padding-top` & `scroll-padding-bottom` so content never hides behind fixed bars; responsive button grids.
- **Vehicle Status HUD:** Displays Maintenance readiness (`0 / 23 checked`), Next PMS (`5,000 km`), Battery status, Coolant status, Tire pressure status, Fuel economy, and direct **Continue Inspection** + **Log Oil Change** quick actions.
- **Parts Finder Enhancements:** Added `Compatible · Verified` vs. `Not Verified · Check Fit` badges, one-tap **Copy OEM #** button, Japanese cross-reference codes, and a full **View Specs** detail modal.
- **Vehicle Tools Center:** Added interactive **Battery & Alternator Voltage Checker**, **OBD-II & Isuzu Diesel Code Library**, **Fuse & Relay Box Finder**, and **Visual Inspection Guides** (Tire, Brake, Coolant, Belt, ATF).
- **Emergency & Roadside Fallback Center:** Dedicated safety-first guides for overheating, brake failure, tire blowout, dead battery/no-start, electrical smoke/fire, and breakdown trunk checklist.
- **Vehicle Resale Value Log:** Track estimated market value, condition grade, and value-adding overhauls alongside JSON backup/restore.
