# Isuzu Crosswind Maintenance & Parts Guide PWA (All Versions 2001–2017)

Live App: **https://esp046-cyber.github.io/isuzucrosswindcarguide/**

A zero-dependency, mobile-first Progressive Web App (PWA) containing complete maintenance schedules (First Check, Monthly/BLOWBAGETS, Quarterly 5,000 km, Semi-Annual, and Major PMS), an all-generation model matrix (XL, XT, XTO, XTi, XUV, XUVi, Sportivo, Sportivo X), a searchable OEM & replacement parts catalog, and an offline **Service Log & Quick Specs** tracker.

## Update Your Repository Using Only an iPhone
1. Download and unzip `isuzucrosswindcarguide-pwa.zip` inside the iOS **Files** app.
2. Open Safari on your iPhone and go to `https://github.com/esp046-cyber/isuzucrosswindcarguide`.
3. Tap **Add file** → **Upload files**, select the extracted files (`index.html`, `style.css`, `script.js`, `manifest.json`, `service-worker.js`, `offline.html`, `favicon.ico`, `icon-192.png`, `icon-512.png`, etc.), and tap **Commit changes**.
4. Wait ~60 seconds for GitHub Pages to redeploy `https://esp046-cyber.github.io/isuzucrosswindcarguide/`, then reload the page in Safari (Service Worker v2.0.0 will automatically replace the old cache).
