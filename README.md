# Isuzu Crosswind Maintenance & Parts Master PWA (All Versions 2001–2017)

A zero-dependency, mobile-first Progressive Web App (PWA) containing complete maintenance schedules (First Check, Monthly/BLOWBAGETS, Quarterly 5,000 km, Semi-Annual, and Major PMS), an all-generation model matrix (XL, XT, XTO, XTi, XUV, XUVi, Sportivo, Sportivo X), a searchable OEM & replacement parts catalog, and an integrated **Claude.ai ChatPrompt Maker**.

## Upload to GitHub Using Only an iPhone (No Codespace Needed)
1. Download and unzip `isuzu-crosswind-pwa.zip` inside the iOS **Files** app.
2. Open Safari on your iPhone, log in to [github.com](https://github.com), and create a new **Public** repository (e.g., `isuzu-crosswind-pwa`).
3. Tap **uploading an existing file** on the repository page.
4. Select all files and folders from the unzipped directory and tap **Commit changes**.
5. Go to **Settings -> Pages**, set **Source** to `Deploy from a branch`, select `main` and `/ (root)`, and tap **Save**.
6. Open the live GitHub Pages URL in Safari, tap the **Share** icon, and choose **Add to Home Screen**.
