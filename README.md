# Crosswind Garage — Complete Maintenance & Parts Guide (2001–2017)

Live App: **https://esp046-cyber.github.io/isuzucrosswindcarguide/**

### Implemented Features
1. **Maintenance Dashboard & Readiness Counter** (Last service, Next Maintenance 5,000 km target, overdue alerts, accurate `0 / 23` task tracking).
2. **5,000 km & Date-Based PMS Reminder System**.
3. **Repair Cost Tracker** (Parts & labor breakdown, monthly and year-to-date totals in PHP).
4. **Parts Compatibility Checker** (Filter by 4JA1, 4JA1-T, or 4JK1-TC + OEM & Japanese replacement part numbers).
5. **Vehicle Maintenance History + JSON Backup/Restore + PDF Print Report**.
6. **Diesel Troubleshooting Guide** (Overheating, hard starting, black smoke, vacuum brake assist).
7. **Daily, Long-Trip, First Check, Monthly, Quarterly, Semi-Annual & Major PMS Checklists**.
8. **Fuel Consumption Calculator (km/L & cost/km)**.
