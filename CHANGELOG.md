# Changelog

## [6.0.0] - 2026-11-16
### Added
- **Emergency Center 10-Tool Suite (`#emergency`):**
  - Searchable & filterable emergency guides covering Engine Overheating, Brake Failure, Tire Blowout, Battery Failure, Engine Won't Start, Smoke/Burning Smell, and Roadside Breakdown steps.
  - Expandable `<details>` step-by-step safety procedures with critical red safety callouts (never open a hot radiator, never work under an unsupported jack, never drive with brake failure).
  - **Emergency Contact Directory (Tool 8):** Preloaded Philippine emergency/expressway numbers (`911`, `136`, NLEX/SLEX) plus custom mechanic/tow contact saver with one-tap `tel:` links.
  - **Vehicle Emergency Preparation Checklist (Tool 9):** 8-item interactive trunk readiness checklist with green verified badge only when 100% packed.
  - **Emergency Incident Notes & History (Tool 10):** LocalStorage-persisted incident logger integrated with JSON backup/restore.
  - Printable Emergency Checklist button, Back to Top button, and Back to Dashboard button.
  - Expanded `<noscript>` static emergency fallback instructions when JavaScript is disabled.

## [5.0.0] - 2026-11-16
- Added Vehicle Status HUD, Vehicle Tools Center (Battery Voltage Checker, OBD-II Code Library, Fuse & Relay Finder), and Resale Value Log.
